# Contributing to Yatta

Thanks for helping. Yatta is a backend framework for Bun. It works with
almost no setup. This guide keeps things simple.

## Quick start

```bash
bun install
bun run dev
```

That is all you need to run the server on your own machine.

## Run the tests

```bash
bun test
```

Run the tests before you send a change. All tests must pass.

To check the code for type errors, run:

```bash
bun run typecheck
```

## How to send a change

1. Make a small change. One change per pull request.
2. Add a test for your change when you can.
3. Run `bun test` and make sure it passes.
4. Open a pull request and explain your change in plain words:
   what you changed, and why.

## How to report a problem

Open an issue and tell us:

- What you did.
- What you expected to happen.
- What happened instead.

Small, clear reports help the most. Thank you.
